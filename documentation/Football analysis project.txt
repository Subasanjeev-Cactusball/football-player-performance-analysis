# Football Player Performance Analysis | 2024–2025

## Project Overview

The Football Player Performance Analysis project focuses on analyzing football player statistics from the 2024–2025 season using Python, SQL, and Power BI.

The objective is to transform raw football statistics into meaningful insights that help understand player performance, goal contributions, club performance, playing time, and position-wise statistics.

This project demonstrates an end-to-end Data Analytics workflow, including data cleaning, exploratory data analysis, SQL querying, and interactive dashboard development.

## Project Objectives

- Analyze individual football player performance.
- Identify the top goal scorers and assist providers.
- Compare actual goals with expected goals (xG).
- Analyze player distribution across different positions.
- Evaluate club-wise goal performance.
- Understand player workload and playing time.
- Develop an interactive Power BI dashboard.

## Project Workflow

### 1. Data Collection

Collected football player statistics for the 2024–2025 season.

The dataset contains player-related information such as:
- Player name
- Nationality
- Club
- Competition
- Position
- Age
- Matches played
- Minutes played
- Goals
- Assists
- Expected goals (xG)
- Shots
- Tackles
- Interceptions
- Passing statistics

### 2. Data Cleaning and Preprocessing – Python

Used Python and Pandas to perform data cleaning operations.

Activities included:
- Inspecting dataset structure.
- Identifying missing values.
- Checking duplicate records.
- Cleaning column names.
- Removing unnecessary whitespace.
- Checking data types.
- Preparing a cleaned dataset for analysis.

### 3. Exploratory Data Analysis – Python

Performed exploratory data analysis to identify performance patterns.

Analysis included:
- Top 10 goal scorers.
- Top 10 assist providers.
- Age distribution.
- Player distribution by position.
- Club-wise goal performance.
- Player goal contributions.
- Statistical visualizations.

### 4. SQL Analysis – MySQL

Imported the prepared football player data into MySQL.

Performed SQL analysis using:

- SELECT statements
- WHERE conditions
- GROUP BY
- ORDER BY
- Aggregate functions
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- RANK()

### 5. Interactive Dashboard – Power BI

Developed a three-page interactive dashboard.

**Page 1 – Overall Performance**
- Total Goals
- Total Assists
- Total Players
- Total Minutes
- Total Shots
- Total Expected Goals
- Top 10 Goal Scorers
- Top 10 Assist Providers
- Top 10 Clubs by Goals

**Page 2 – Player Performance Analysis**
- Player Distribution by Position
- Goals vs Assists Analysis
- Actual Goals vs Expected Goals

**Page 3 – Player Workload Analysis**
- Average Playing Minutes by Position
- Matches Played vs Minutes Played

### Interactive Features

- Club selection slicer.
- Position selection slicer.
- Competition selection slicer.
- Synchronized filters across all three dashboard pages.
